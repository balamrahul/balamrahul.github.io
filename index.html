Threat hunting

Hypothesis → query → evidence

Hunting work is presented as an investigation process, not a dump of queries.

HUNT 01

Password Spray

Hypothesis: an attacker is attempting low-and-slow authentication against multiple users from shared infrastructure.

Evidence: failed sign-ins → source IP → targeted users → successful authentication
HUNT 02

Suspicious PowerShell

Hypothesis: unusual PowerShell execution may indicate script-based execution or hands-on-keyboard activity.

Evidence: process lineage → command line → user → network activity
HUNT 03

IOC Pivot

Hypothesis: a known IP, domain, hash or account indicator may have related activity elsewhere in the environment.

Evidence: indicator → identity → endpoint → network → scope
